# 本地管理后台

[English](GUI.en.md)

## 定位

管理后台是面向普通用户的主要控制界面，不是服务器管理员后台。它默认只绑定
`127.0.0.1`，直接读取本地 vault，不部署到公网。当前 SQLite 内容本身不是应用层加密，静态保护
依赖操作系统磁盘加密；界面不会把它误称为已加密 vault。

## 当前可运行原型

```bash
contextvault ui
```

然后打开 `http://127.0.0.1:8787`。

当前实现：

- vault 资料、候选、账号、设备、空间、路线和回执数量总览；
- AI 账号列表和新增本地账号引用；
- 身份空间列表和创建；
- 手动候选、ChatGPT 导出导入、单项/批量确认和拒绝；
- 设备白名单扫描和设备环境列表；
- 同步路线创建、半自动/全自动策略、间隔与风险确认、最终内容预览和回执生成；
- 敏感同步总开关、风险确认、事件历史和同步回执；
- 响应式桌面与移动布局；
- 仅 loopback 监听，拒绝绑定公网地址。

## 页面结构

### 总览

- 已确认资料、待审阅、AI 账号和设备数量；
- 资料健康度；
- 各个 AI 账号知道什么；
- 最近资料变化和同步状态；
- 高风险或冲突提醒。

### 用户资料

- 按身份、教育、工作、偏好、技能、项目、关系和事件分类；
- 候选、已确认、冲突、过期和已拒绝过滤；
- 展示来源、置信度、时间和敏感级别；
- 批量确认、编辑、过期和拒绝。

### AI 账号

- 个人、工作和客户账号；
- 账号状态和最近识别时间；
- 本地标签，不显示或保存认证秘密；
- 断开、撤销和重新识别。

### 身份空间与同步路线

- 管理 personal、work、client 和 anonymous 空间；
- 可视化来源账号、空间、目标账号；
- 为每条 route 配置资料类别、敏感模式和自动同步。

### 设备

- 设备型号、OS、开发工具和最后扫描时间；
- 查看扫描 diff；
- 配置采集白名单；
- 明确展示被拒绝的秘密类别。

### 附件引用

- 按来源 AI 账号显示附件；
- 区分引用存在和当前设备可访问；
- 显示 active、需要登录、过期、丢失和无权限状态；
- 选择只同步引用、提取文本或即时转传；
- 不提供默认云端文件仓库。

### 隐私与授权

- 敏感同步全局开关；
- 按账号、类别设置 block、ask、allow；
- 风险提示和免责声明版本；
- 同意记录、撤销和重新确认。

### 同步历史

- 新增、修改、过期和删除 diff；
- 目标平台和具体账号；
- 实际发送内容与 Claim manifest；
- 验证结果、纠正和撤销状态。

## 安全约束

- 默认只允许本机访问；
- 所有修改 API 需要限制请求大小和校验字段；
- 不从浏览器读取或展示密码、Cookie、token；
- 后续若允许局域网访问，必须先加入认证、TLS 和 CSRF 防护；
- 不应把本地后台直接部署到公网作为多用户 SaaS。
